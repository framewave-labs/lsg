# A2팀 IA — 인수인계본 v3.0
> 작성일: 2026-07-12 | 인수인계본 정리일: 2026-08-02 | 작성자: 이슬기 (PM)
> GeNova 전체 화면 구조를 실제 배포 서비스(`kx-frontend-azure.vercel.app`) 기준으로 정리한 문서다. v2.0의 화면 트리 구조에, 설계 문서(v0.1~v0.8)와 `2026-08-02_기능명세서_v3.0.md`에 있던 옵션 값·입력 제약·API 정보를 각 노드에 병합해 이 문서만으로도 화면별 세부 사양까지 파악할 수 있게 했다. 더 긴 서술(에러 처리, 인수 조건 등)은 기능명세서 쪽이 원본이며, 여기서는 트리 구조에 붙는 수준으로만 압축했다. 엑셀본은 `2026-08-02_생성형AI통합엔진_A2_IA_v4.xlsx` 참고.
> "확인됨"과 "설계 당시 사양(재확인 필요)"을 구분해 표기했다.

## 전체 구조

```
비로그인
├── 홈 (랜딩) — 히어로 + 원터치 프롬프트 입력바
├── 로그인
│   ├── 이메일/비밀번호 — 실패 시 "이메일 또는 비밀번호를 확인해주세요"(가입 여부 구분 없음, 설계 당시 사양)
│   └── 구글 계정으로 시작하기 — Google OAuth, 콜백 kx-studio.duckdns.org/login/oauth2/code/google
└── 회원가입 — 3단계 마법사(1/3→2/3→3/3, 확인됨)
    ├── 1단계: 이메일 입력 — GET /api/auth/email/check?email= 호출 (확인됨)
    │   └── ⚠ 현재 503 오류로 다음 단계 진행 불가 (확인됨, 인프라 이슈)
    └── 2·3단계: 비밀번호/비밀번호 확인 추정(설계 당시 사양, 8자 이상 64자 이하) — 재확인 필요

로그인 후
├── 사이드바 (전 화면 공통)
│   ├── 기본: 아이콘만 노출
│   ├── hover 시 확장: 라벨 + 워드마크 + 하단 프로필(이름·이메일) + [로그아웃]
│   └── 메뉴: 홈 · 이미지 · 영상 · 역프롬프트 · 라이브러리
│
├── 홈 화면
│   ├── 히어로 — 카피 "한계없는 상상을, 현실로" + 모델 배지(GPT Image 2.0/Seedance 2.0·Kling 3.0) + 원터치 입력바
│   └── 탐색하기 — 큐레이션 갤러리(유저 발행 아님) · 이미지/영상 탭 · 해시태그 필터
│
├── 이미지 생성 화면 — 모델 GPT Image 2.0 고정
│   ├── 유형: 캐릭터 — 각도(단일/다각도) · 결과: 단일 1장 또는 다각도 세트(추정)
│   ├── 유형: 배경 — 각도 옵션 없음 · 결과: 배경 1장
│   ├── 유형: 캐릭터시트 — [+ 캐릭터 만들기] 진입
│   │   └── 진입 후 상세 화면(자유 텍스트 PART1+PART2 / 속성 사이드바 파트1~5) — 설계 당시 사양, 재확인 필요
│   ├── 공통 옵션 — 비율(1:1 기본/16:9/9:16, 4:3 미지원) · 품질(표준/4K) · 수량 · 레퍼런스(최대 8) · AI 프롬프트 변환(On/Off, 기본 Off)
│   ├── 프롬프트 입력 — 설계 당시 제약: 1자 이상, 최대 2,000자(API 자체 한도 32,000자), 클라이언트 타임아웃 60초
│   └── 결과 → 우측 패널(라이브러리와 공통 컴포넌트)
│       ├── [재편집] · [동영상 만들기] · [다운로드](PNG, image_{YYYYMMDD}_{HHmmss}.png) · [삭제]
│       └── [재생성] — 기존 항목 유지, 새 결과 별도 저장
│
├── 영상 생성 화면
│   ├── 모델: Seedance 2.0 — 길이(4/5/8/10/15초/자동) · 비율(16:9/9:16/1:1/21:9/4:3/3:4/자동) · 품질(고화질1920×1080/표준1280×720/480p/4K) · 레퍼런스 최대 9장
│   ├── 모델: Kling 3.0 — 길이(3/4/5/8/10/15초) · 비율(16:9/9:16/1:1) · 품질 옵션 없음(원인 불명) · 레퍼런스 최대 4장
│   ├── 입력: 스토리보드 업로드(필수 1장, 구 "3x3 그리드") + 레퍼런스(선택, 모델별 최대치 상이)
│   ├── 생성 상태 — 대기(IN_QUEUE)→진행(IN_PROGRESS)→완료(COMPLETED)/실패(ERROR), 5초 폴링·10분 타임아웃(설계 당시 사양)
│   ├── 오디오 — 상시 포함 여부·토글 유무 재확인 필요
│   └── 결과 → 풀스크린 모달(라이브러리와 공통 컴포넌트)
│       ├── 찜하기(하트)·공유·프롬프트(전체보기/복사)·모델/품질/비율/생성일자/작업ID
│       └── [재편집] · [다운로드](MP4, video_{YYYYMMDD}_{HHmmss}.mp4)
│
├── 역프롬프트 화면
│   ├── 모델: Claude Sonnet 5 · 비율(auto 기본/1:1/16:9/9:16) · 업로드 1장(설계 당시 jpg·png·webp, 10MB 이하)
│   ├── [프롬프트 생성] → "제안된 프롬프트" 결과
│   │   ├── [복사]
│   │   └── 더보기(⋮) → [수정](프롬프트+비율) · [이 프롬프트로 생성하기]
│   ├── 분석 태그(스타일/조명/구도/렌즈/색감/분위기) 노출 여부 — 설계 당시 사양, 재확인 필요
│   └── ※ 추출만으로는 미저장, [이 프롬프트로 생성하기] 실행 결과만 라이브러리 저장
│
├── 라이브러리 화면
│   ├── 세그먼트: 내 작업 / 찜한 목록
│   ├── 필터: 전체 / 이미지 / 영상
│   ├── 정렬: 최신순 / 오래된순
│   ├── API(확인됨): GET /api/media/files?type={IMAGE|VIDEO}&page=&size= · GET /api/media/images/{id}/download
│   └── 상세보기
│       ├── 이미지 → 우측 패널 — [재편집]·[동영상 만들기]·[다운로드]·[삭제]
│       └── 영상 → 풀스크린 모달 — 핸들(@my_studio)·찜하기·공유·프롬프트·메타정보·[재편집]·[다운로드]
│   └── 삭제 — 확인 모달(설계 당시 사양) → DELETE 요청 → 그리드 즉시 제거
│
└── 내 프로필 화면 (아바타 클릭 진입, API 확인됨: GET /api/me/profile)
    ├── 프로필 카드 — 이미지 변경 · 스튜디오 이름(텍스트+저장) · 이메일(표시만)
    │   └── 설계 당시엔 "닉네임"+로그인방식뱃지+가입일이었으나 실제 화면엔 없음
    ├── 활동 카드 — 내 생성 이력 → [라이브러리로 이동] (수치 표시 없음)
    └── 위험 구역 — [계정 삭제] → 브라우저 기본 confirm() (커스텀 체크박스 게이트 모달 아님)
```

## 확인되지 않은 사항

- 회원가입 2·3단계 필드 구성 — 이메일 확인 API(503) 문제로 진행 불가, 재확인 필요
- 캐릭터시트 [+ 캐릭터 만들기] 진입 이후 상세 화면 구성(자유 텍스트 vs 속성 사이드바)
- Kling 3.0 품질 옵션 부재 원인
- 찜하기(하트) 아이콘이 이미지 상세 패널에도 있는지
- 라이브러리 상세보기 이미지=패널/영상=모달 차이가 의도된 설계인지
- 영상 오디오 상시 포함 여부·토글 유무
- 역프롬프트 분석 태그(6종) 실제 노출 여부
- `@my_studio` 핸들과 "스튜디오 이름" 필드의 관계
- 사전 프롬프트 가이드·공유 기능 진입점
- 이미지·영상 생성 요청(POST), 라이브러리 삭제·찜 토글 API의 정확한 경로
