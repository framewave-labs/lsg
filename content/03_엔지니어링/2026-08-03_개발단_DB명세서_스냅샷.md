# DB 명세서 (개발단 원본, 스냅샷)

> ⚠ **이 문서는 개발단(BE)이 Notion에서 자체적으로 관리하던 DB 설계 자료를 2026-08-03에 원본 그대로 내보낸 것입니다.**
> 개발 초중반 시점의 설계 스냅샷으로 보이며, 실제 운영 DB 스키마와 컬럼명·타입이 다를 수 있습니다(예: `MediaFile.file_path`가 실제로는 S3 경로를 담는지, 로컬 경로만 담았던 시점 기준인지 등은 별도 확인 필요).
> **참고용으로만 사용하고, 실제 스키마 확인이 필요하면 BE 담당자에게 직접 `SHOW CREATE TABLE` 또는 JPA 엔티티 클래스 확인을 요청하세요.**

## User

| **컬럼명 (Column)** | **타입 (Type)** | **제약조건 (Constraints)** | **설명 (Description)** |
| --- | --- | --- | --- |
| `id` | BIGINT | PRIMARY KEY, AUTO_INCREMENT | 사용자 고유 식별자 |
| `email` | VARCHAR(100) | NOT NULL, UNIQUE | 로그인 및 커뮤니케이션용 이메일 |
| `password` | VARCHAR(255) | NOT NULL | 암호화된 비밀번호 |
| `nickname` | VARCHAR(50) | NOT NULL | 서비스 내 노출될 닉네임 |
| `role` | VARCHAR(20) | NOT NULL | 회원 권한 (예: `USER`, `ADMIN` 등 Enum 매핑) |
| `created_at` | TIMESTAMP | NOT NULL, DEFAULT NOW() | 계정 생성 일시 |
| `updated_at` | TIMESTAMP | NOT NULL, DEFAULT NOW() | 계정 정보 수정 일시 |

## MediaFile

| **컬럼명 (Column)** | **타입 (Type)** | **제약조건 (Constraints)** | **설명 (Description)** |
| --- | --- | --- | --- |
| `id` | Long | PRIMARY KEY | 자산 고유 식별자 |
| `type` | VARCHAR(10) | NOT NULL, CHECK (`type` IN ('IMAGE', 'VIDEO')) | 파일 타입 구분 |
| `file_path` | VARCHAR | NOT NULL | AWS S3 또는 로컬 전체 경로 |
| `origin_prompt` | VARCHAR | NOT NULL | 생성에 사용된 원본 프롬프트 |
| `reversed_prompt` | VARCHAR | NULL | 이미지 분석을 통해 추출된 역프롬프트 |
| `tags` | VARCHAR(512) | NULL | 검색 및 필터링용 태그 문자열 |
| `created_at` | TIMESTAMP | DEFAULT NOW(), NOT NULL | 생성 일시 |

## GenerateJob

| **컬럼명 (Column)** | **타입 (Type)** | **제약조건 (Constraints)** | **설명 (Description)** |
| --- | --- | --- | --- |
| `id` | Long | PRIMARY KEY | 작업 고유 식별자 |
| `file_id` | Long | NULL, REFERENCES `media_file`(`id`) | 완료(`SUCCESS`) 시 생성된 파일 ID (FK) |
| `type` | VARCHAR(20) | NOT NULL | 작업 유형 (`IMAGE`, `VIDEO`, `PROMPT`) |
| `status` | VARCHAR(20) | NOT NULL, DEFAULT 'PENDING' | 진행 상태 (`PENDING`, `RUNNING`, `SUCCESS`, `FAILED`) |
| `created_at` | TIMESTAMP | DEFAULT NOW(), NOT NULL | 작업 요청 시간 |
| `updated_at` | TIMESTAMP | DEFAULT NOW(), NOT NULL | 마지막 상태 변경 시간 |
